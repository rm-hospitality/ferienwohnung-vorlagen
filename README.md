# Ferienwohnung Vorlagen: kostenlose Checklisten und Rechner für Gastgeber

Kostenlose, frei nutzbare Vorlagen für alle, die eine Ferienwohnung vermieten: Reinigungscheckliste, Hausordnung, Ausstattungs-Checkliste, Willkommensmappe, Nachrichtenvorlagen für Gäste und ein Mindestpreis-Rechner pro Nacht. Aus der Praxis von [RM Hospitality](https://www.rm-hospitality.de/ratgeber?utm_source=github&utm_medium=tool&utm_campaign=parasite-seo-2611), Bamberg. Wir betreuen rund 70 Ferienwohnungen in Deutschland, Österreich und Italien.

**Direkt nutzen:** https://rm-hospitality.github.io/ferienwohnung-vorlagen/

## So verwenden Sie die Vorlagen

1. Vorlage öffnen, oben rechts auf „Raw“ oder „Download“ klicken, oder das PDF laden.
2. In Word, Google Docs oder Pages einfügen und die Platzhalter in [eckigen Klammern] ersetzen.
3. Für die Hausordnung: Die wichtigsten Regeln gehören zusätzlich ins Inserat, damit Gäste sie vor der Buchung sehen.

## Mindestpreis-Rechner

Der Rechner läuft komplett im Browser (keine Cookies, kein Tracking). Er rechnet:

```
Aufenthalte        = belegte Nächte ÷ Nächte pro Aufenthalt
Benötigter Umsatz  = (Fixkosten + Aufenthalte × Kosten je Aufenthalt + Gewinnziel)
                     ÷ ((1 − Plattformgebühr) × (1 − Verwaltung))
Preis pro Nacht    = (Benötigter Umsatz − Aufenthalte × Reinigungsgebühr) ÷ belegte Nächte
```
